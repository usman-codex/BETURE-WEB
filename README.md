# BETURE-WEB

Official website for **Beture Web** - Modern Web & AI Development, Digital Engineering, and Tech Solutions.

## Brand Identity & Colors
- **Primary Dark Navy**: `#011337`
- **Royal Electric Blue**: `#2E54AD`
- **Vibrant Electric Cyan**: `#16A5CE`

## Features
- Complete responsive frontend with modern UI/UX
- Interactive course catalog & details
- Full services catalog with project showcases
- Job career portal with resume upload system
- Master Claude prompt modal & blog system

## Run Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
